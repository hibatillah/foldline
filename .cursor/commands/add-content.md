# Add content

Add your own page, activity or page settings to Foldline from a plain description, ready for a pull request. The description is what the contributor typed after the command.

1. Read `.agents/skills/add-content/SKILL.md` and follow it. It points to `.claude/agents/add-content.md` and `docs/how-to/add-your-content.md`.
2. Stay inside the contributor's own files. Do not commit or push.

If the description is empty, ask the contributor to describe the page, the activity or the settings in a few sentences, and stop.
