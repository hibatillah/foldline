# Test map

> **Reference.** Read when: you need which file tests which behavior. Skip if: you write a test; see [test and snapshot](../how-to/test-and-snapshot.md).

## Where the tests live

Each test sits in the file it tests, in a `#[cfg(test)] mod tests` block at the bottom. There is no separate `tests/`
folder, because the notch is a binary crate and an outside test folder could not reach its internals. The tests are
spread over many files:

| Area | Files with tests |
| --- | --- |
| page contract | `crates/notch/src/page.rs` |
| activity contract | `crates/notch/src/activity.rs` (change detection) |
| host | `crates/notch/src/host/notch/` (`layout.rs` the open height, `animation.rs` size springs and bounds, `keyboard.rs` text keys, `pages.rs`, `row_motion.rs` the per-item springs; `tests/` the hiding rules, screen modes, settings reload, page navigation, `page_states.rs` and `clipboard_states.rs` (pictures of page states, ignored by default), `resting_row.rs` (the empty pill, the group order, the dot column, the clock's glide, the lyric pill's group and dot), `row_motion.rs` (the frame timer stops after items come and go) and `header_row.rs` (the gear, the icons, the clicks, the clock) on an off-screen notch), `navigation.rs` (page order, page choice by priority, the dots' spring), `page_swap.rs` (the swap's timing, direction, overlap and its end after the size spring), `scroll_gate.rs` (wheel cooldown, swipe accumulation), `motion.rs` (spring damping ratio), `pill_row.rs` (idle and header row positions, the empty pill, gaps, hit areas), `claimed_row.rs` (the lyric pill's lead, dots and group), `activity_layout.rs`, `registry.rs`, `settings.rs`, `tray.rs` (menu commands), `settings_launcher.rs`, `screen_mode/classify.rs` (maximized, full screen, a screenshot overlay), `screen_mode.rs` (an ignored check against a real window), `screen_mode/location_hook.rs` (when moves count as a flood and pause the hook; unit tests beside the code), `startup.rs`, `visibility.rs` (the showing words, old keys), `notification_banners/backup.rs` (the saved values and what a pass changes), `volume_flyout/identity.rs` (which window is the flyout) |
| drawing toolkit | `crates/notch/src/gfx/color.rs`, `geometry.rs`, `spring.rs`, `image_data.rs`, `image_brush.rs`, `path.rs`, `svg_path.rs` (SVG path data: lines, arcs, closes), `raster.rs`, `canvas.rs` (flare shape), `text_cache.rs` (the cache holds at most 64 results and drops the oldest) |
| widgets | `crates/notch/src/ui/icon_button.rs`, `pill_button.rs` (hover colors), `bitmap_square.rs`, `icons/tests.rs`, `outline.rs`, `ring.rs`, `hud.rs`, `text_field.rs` (editing keys); `icons/tests.rs` includes the gear (a hexagon around a ring) |
| shalat page | `crates/notch/src/pages/shalat/times.rs` (the calculation, checked against Aladhan's Kemenag times for Jakarta), `config.rs`, `schedule.rs` and `text.rs` (settings, the minute-by-minute waiting rules, wording), `arc.rs` (the sun arc through the markers, the sun's place by time), `day.rs` (the heading, the marker states), `tests.rs` |
| weather page | `crates/notch/src/pages/weather/draw.rs` (the six cells, the left column), `alert.rs` (the banner height, wording and buttons), `badge.rs` (the countdown text and timing), `link.rs` (the weather.com addresses of a clicked hour or day), `click.rs` (the cell hit test and what each opens), `message.rs` (the row message states and their width), `picture.rs` (every sky has its picture), `forecast.rs` (the response), `symbol.rs`, `tests.rs` (the page's collapsed and alert states), `refresh.rs` (fetch and alert scheduling) |
| todo page | `crates/notch/src/pages/todo/list.rs` (the file format, order, add/tick/remove), `layout.rs` (the rows, Add last, the five-row limit, heights, the empty page), `mod.rs` (width, limit), `draw.rs` (the count) |
| timer page | `crates/notch/src/pages/timer/session.rs` and `session/` (rules, saving, wake times), `view.rs`, `layout.rs`, `tests.rs` (the page's collapsed pill and header) |
| clipboard page | `crates/notch/src/pages/clipboard/item.rs` (kinds, wording, ages), `history.rs` (the 7-item and byte limits, move to front, undo), `capture.rs` (text and picture limits, skipped copies), `dib.rs` (bitmaps in and out), `preview.rs` (line wrapping), `layout.rs` (places, hit targets, double click timing), `tests.rs` (the states of the design); `crates/notch/src/platform/clipboard.rs` (text decoding); the pictures are `cargo test clipboard_state -- --ignored` |

| devices page | `crates/notch/src/pages/devices/model.rs` (which devices (the five lowest batteries), order, battery color, dash, "Off", kinds), `merge.rs` (Bluetooth plus receiver devices, kinds, battery and charging, the empty and Bluetooth-off messages), `draw.rs` (a long name is cut inside 76 px), `layout.rs` (cells and lines stay inside the page), `ring.rs` (steps and dashes), `tests.rs` (page answers, every state), `sample.rs` (the states of the design) |
| shelf page | `crates/notch/src/pages/shelf/items.rs` (the list, wording, saving), `layout.rs` (places, hit targets, name lines, double click), `tests.rs` (arrival) |

| calendar page | `crates/notch/src/pages/calendar/dates.rs`, `ics/` (reading and repeating), `agenda.rs` (the five closest events, done for today), `geometry.rs` (the month grid, the event viewport, rows), `labels.rs` (month and empty-day wording), `wake.rs` (when the page wakes and downloads, also while hidden), `local_time.rs`, `settings.rs`, `tests.rs` (the empty-day and done-for-today states), `fetch.rs` |
| notifications activity | `crates/notch/src/activities/notifications/items.rs` (the wording), `card.rs` (the card's height and lines), `rounds.rs` (the rounds of asking by id), `listener.rs`, `mod.rs` (how long the card stays, the buttons); `crates/notch/src/platform/toast_activation/` (`payload.rs` the toast XML, `stored_payload.rs` the database read, `activator.rs` the activator lookup, `click_limits.rs` the click's deadline and the cap on stuck activator threads; the check that a window came forward is `came_forward` in `payload.rs`), `crates/notch/src/ui/banner_buttons.rs` (the Dismiss and Open pair) |
| settings window | `crates/settings/src/` (`palette.rs` contrast, the header fill and the palette per theme, `sidebar.rs` the groups and their order, `header.rs` the breadcrumb of every section, `icons.rs` that every bundled icon is served as a 24 grid SVG and the hex nut's shape, `brand.rs` the stable or dev tile, `main.rs` `opening_size` (default, shrunk, never below the minimum), `sections/mod.rs` writing keys, one icon and one description per page, About last in the footer, `sections/about/` (rows and inert buttons in `mod.rs`, the licenses search in `licenses.rs`, the settings file and data folder in `paths.rs`), `sections/pages.rs`, `sections/behavior.rs`, `sections/shalat/`, `field.rs`, `picture.rs`, `location.rs`); run with `cargo +stable-x86_64-pc-windows-msvc test --workspace`. `crates/places/src/lib.rs` (the city list and search order) |
| the page header and the page list | `crates/notch/src/host/chrome.rs` (the page dots start at the header's left edge), `navigation.rs` |
| activities | `crates/notch/src/activities/battery.rs` (charge rules, the ring's color, arc and presence, no ring on a PC), `device_battery/` (the crossing rules, the connect rule, device naming, the watcher values; an ignored probe against real hardware), `volume.rs` and `caps_lock.rs` (the icon badge, the message over it, the ranks), `camera.rs`, `privacy.rs` (the dot companion's presence) |
| media page | `crates/notch/src/pages/media/tests.rs`, `layout.rs` (control and badge places), `lyric_panel.rs` (line fade), `backdrop.rs` (glow ramp), `resting.rs` (lyric pill width, where the line starts), `session.rs`, `lyric_follower.rs`, `lyrics/mod.rs`, `lyrics/client.rs` |

To run one file's tests, or a single test, filter by name:

```
cargo test lyric_follower
cargo test a_paused_track_keeps_its_line_but_arms_no_timer
cargo test -- --nocapture
```
